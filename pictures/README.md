# Screenshots

Drop your README screenshots here:

| Filename | What to capture |
|---|---|
| `01-overview.png` | Main window — form tabs visible on the left, editor or simulator on the right. Take it after loading an official preset (e.g. Climb) so the LCD preview shows menu items. |
| `02-wizard.png` | The "New from wizard…" dialog (Ctrl+Shift+N), ideally on a step that has the side info panel populated (e.g. step 1 with a type selected, or step 2 showing the intensity ceilings). |
| `03-simulator.png` | The Simulator tab while a pattern is running. Should show channel state, the live "Menu controls" sliders, and the 4-lane timeline with the yellow now-cursor visible. |

Recommended size: 1600 × 900 (or whatever your window naturally is at), PNG, no compression.
